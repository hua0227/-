# 设计报告提纲

## 1. 选题意义和目标定位

说明毛细管电泳在药物分析、杂质检测和物理化学教学中的价值，以及虚拟仿真对理解电泳迁移、电渗流和扩散展宽的帮助。

## 2. 物理原理

- 电场强度
- 电泳迁移率
- 电渗流
- 一维对流-扩散方程
- 检测峰、峰宽、理论塔板数和分离度
- 焦耳热与实验限制

## 3. 软件整体结构

- Flutter 跨平台应用层
- 实验库与实验包管理
- `advection_diffusion_1d` 求解器
- 可视化绘制模块
- CSV/JSON 导出模块

## 4. 仿真流程

1. 读取内置实验或导入 `.pexp`。
2. 校验 `manifest.json` 和 `solverId`。
3. 生成毛细管电泳配置。
4. 运行一维对流-扩散模型。
5. 输出区带迁移动画、电泳图谱和定量指标。

## 5. 使用方法

说明 Windows、macOS、Android 安装方式，以及参数范围、预设场景、导出结果方法。

## 6. 结果分析

用典型参数展示电压、电渗迁移率、有效长度和进样区带宽度对迁移时间、峰宽、分离度和焦耳热风险的影响。

## 7. 合理性、局限性和改进

当前模型适合教学演示，暂未包含温度场、管壁吸附、复杂缓冲液化学平衡和真实检测器噪声。后续可加入二维热模型、pH-电离平衡、手性选择剂模型和实验数据拟合。

## 8. 结论

总结本作品在物理正确性、互动性、跨平台安装、更新维护和推广价值方面的特点。
