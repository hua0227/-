# 学术规范说明模板

## 自写代码

- Flutter 应用界面与状态管理。
- 实验库、实验包导入和 `.pexp` 校验逻辑。
- 毛细管电泳一维对流-扩散仿真核心。
- 区带迁移动画、电泳图谱和定量结果绘制。

## 第三方依赖

- Flutter SDK：跨平台应用框架。
- `archive`：读取 zip 格式 `.pexp` 实验包。
- `file_picker`：跨平台选择导入文件。
- `path_provider`：获取应用文档目录，用于保存导入包和导出结果。
- `path`：处理跨平台路径。

## 参考资料

报告与 PPT 中引用参考资料时，应在相应页面标注来源。首批资料包括毛细管电泳教学资料和药物分析相关综述。

如使用 AI 辅助生成文字、代码初稿、配图或配音，应在报告中说明辅助内容、使用方式和人工校核过程。
